# GameDecides

A plugin that periodically changes the rules of the game with random twists.

## About

GameDecides picks a random "twist" every few minutes that affects all players. Some twists help you, some make things harder, and some are just chaotic. It keeps gameplay fresh and unpredictable.

## Features

- 45+ different twists
- Configurable twist interval
- Enable/disable individual twists
- Skip button for unwanted twists
- Works in survival, hardcore, or any game mode
- Full 1.21 support

## Twist Categories

**Movement**

- No jumping
- Super speed
- Slow motion
- Levitation
- Dolphins grace

**Combat**

- One hit kills
- No armor allowed
- Double damage taken
- Infinite arrows
- Weakness applied

**Items**

- Inventory shuffle
- Random item every minute
- No crafting
- Drop on hit
- Inventory lock

**World**

- Permanent night
- Rain of fire
- Random teleports
- Gravity changes

**Misc**

- Shared health
- No hunger drain
- Explosion on death
- TNT spawns randomly
- And many more...

## Commands

| Command | Description |
|---------|-------------|
| `/gamedecides start` | Start the twist cycle |
| `/gamedecides stop` | Stop twists |
| `/gamedecides skip` | Skip current twist |
| `/gamedecides twist <name>` | Force a specific twist |
| `/gamedecides list` | List all twists |
| `/gamedecides reload` | Reload config |

## Installation

1. Download the jar
2. Put it in your plugins folder
3. Restart the server
4. Use `/gamedecides start`

## Configuration

Set the twist duration, enable/disable specific twists, and customize messages in the config file.
