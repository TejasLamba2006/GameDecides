# Changelog

All notable changes to GameDecides will be documented in this file.

## [1.0.0] - 2025-01-02

### Added

- Initial release with 45+ unique twists
- Classic twists: Dream Luck, Chad Gear, Stay Away, Ghost Mode, Squid Game, Faith Leap, Bird Mode, Dwarf Mode, Piglin Life, Health Pack, Reverse Karma, Surprise
- Movement twists: Low Gravity, Speed Demon, Turtle Mode, Bouncy World, Dolphin Grace
- Combat twists: Glass Cannon, Thorns Everywhere, Vampiric, One Tap, Pacifist, Explosive Arrows, Fire Touch
- 1.21 themed twists: Breeze Attack, Vault Hunter, Mace Mayhem, Ominous Aura
- Chaos twists: Inventory Swap, Position Shuffle, Random Teleport, Backwards Day, No Jump, Blindfolded
- Environmental twists: Eternal Night, Rain of Fire, Lightning Storm, Mob Mayhem
- Utility twists: Shared Damage, Lucky Blocks, No Tools, Magnetic, Starter Kit
- Fun twists: Giant Mode, Baby Mode, Levitation, Freeze, Hot Potato
- Full configuration system for all twists
- World blacklist support
- Bypass permission for staff
- Customizable messages, sounds, and titles
- Admin commands (start, stop, skip, list, info, reload)
- SMP Core advertisement for non-users
